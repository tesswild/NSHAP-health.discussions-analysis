# NSHAP-health.discussions-analysis
R code for NSHAP Waves 1 &amp; 2 health discussions analysis

The NSHAP data files are not included in this repository. Researchers should download the data files here: https://www.icpsr.umich.edu/sites/nacda/view/collections/706

# Running the analysis

1. Open the R Script
2. Download the required R data files and place them in the working directory
3. Install and load required packages
4. Run commands in script
